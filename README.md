# Vortex Alpha

Sıfırdan yazılmış hobi işletim sistemi. Yapımcı: Selimhanko Games.

## İndir
Sağdaki **Releases** bölümünden `Vortex-Alpha-yama49.iso` dosyasını indir.

## VirtualBox ile kurulum
1. VirtualBox'ı kur (virtualbox.org).
2. Yeni → Tür: Other, Sürüm: Other/Unknown (32-bit).
3. Bellek: 128 MB veya fazlası. Sabit disk: 64 MB (VDI), IDE denetleyici.
4. Ayarlar → Sistem → EFI etkinleştir KAPALI.
5. Ayarlar → Ekran → Grafik denetleyici: VBoxVGA, video belleği 16 MB.
6. Ayarlar → Depolama → Optik sürücü: indirdiğin ISO.
7. Başlat. İlk açılışta Kurulum sihirbazı gelir.

Disk seçersen dosyaların kalıcı olur. Disksiz (canlı) modda kapatınca her şey silinir.

Gerçek bilgisayarda denenmemiştir, sanal makinede çalıştırın.
